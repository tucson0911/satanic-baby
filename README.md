# Satanic Baby

A 2D comedy-horror game created for our prototype game jam.

## Engine

Godot 4.7.2 Standard

## Language

GDScript

## Setup

1. Install Godot 4.7.2 Standard.
2. Clone this repository.
3. Open `project.godot`.
4. Press F5 to run.

## Git Workflow

Do not develop directly on `main`.

Create a branch directly on [Repo branches](https://github.com/tucson0911/satanic-baby/branches)

Push the branch and create a Pull Request when the feature is ready.
